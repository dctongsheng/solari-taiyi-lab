# Solari Taiyi Lab Website

这是 Solari Taiyi Lab 官方网站的 1:1 完整还原版本。

## 项目特点

- **React + Framer Motion**: 使用 React 和 Framer Motion 构建的动态交互网站
- **鼠标跟随动画**: 光学场效果随鼠标移动产生渐变和光晕效果
- **多页面导航**: 包含 Home、About、Careers 等页面
- **响应式设计**: 完美适配桌面和移动设备
- **无需构建**: 单文件 HTML，直接在浏览器中打开即可运行

## 文件结构

```
.
├── index.html    # 完整的单文件网站（包含所有 React 代码和样式）
└── README.md     # 说明文档
```

## 如何使用

直接在浏览器中打开 `index.html` 文件即可查看网站。

## 技术栈

- React 18 (通过 CDN)
- Framer Motion 11 (通过 CDN)
- Tailwind CSS (通过 CDN)
- Babel Standalone (用于浏览器内 JSX 转译)

## 页面说明

- **首页**: 展示 Solari 品牌和核心价值主张
- **About**: 介绍实验室的使命和方向
- **Careers**: 招聘职位信息
